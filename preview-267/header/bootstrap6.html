Notes

  • the data-form-type="other" attribute used on the feedback form is a workaround for a bug in Dashlane password manager. See https://github.com/sul-dlss/vt-arclight/issues/495
  • for applications not using the application subtitle span element, it can simply be removed.
  • for applications not using the second row of nav links, the .navbars element can be removed.
  • the top row of nav links must be duplicated inside the masthead's navbar, or they will not appear on mobile.
  • For applications using the stacked image on mobile, add the class `stacked-mobile` to the `navbar-logo`
  • You can set the container class on the identity bar, navbar and masthead, to lg:container if the page content also uses lg:container (such as searchworks)
