Steps:
  1. Copy this file to bootstrap6.html in a folder with the name of the component, i.e. forms/bootstrap6.html
  2. Every component also needs a Bootstrap 5 version: copy the Bootstrap 5 template to bootstrap5.html in the same folder. The badge line under the title links the two versions to each other.
  3. Add an index.html to the folder that lets people choose a version (copy one from another component folder)
  4. Use Bootstrap 6 markup (e.g. btn-solid theme-primary, md:d-none) and the sul-bs6.css stylesheet; put component styles in styles/bs6/
  5. Delete everything from delete start to delete end (commented in the file)
  6. Replace with HTML for page. For the HTML you want to populate the HTML code section below add the variable data-html-target="name_of_element"

Notes: If you have multiples html elements on the page, i.e. banners, links, etc. make sure name_of_element in data-html-target is a human readable value that will go into the dropdown that gets auto generated Below you will see an example of this
